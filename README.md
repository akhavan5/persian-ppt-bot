# ربات تلگرام ساخت پاورپوینت فارسی (Cloudflare Workers)

کاربر در تلگرام فقط **موضوع** را می‌فرستد؛ ربات سرفصل و محتوا را با هوش مصنوعی می‌نویسد، فایل **PPTX راست‌به‌چپ و قابل ویرایش** می‌سازد و همان‌جا می‌فرستد. نیازی به ویرایش در تلگرام نیست.

```
تلگرام ──webhook──▶ Worker (src/index.ts) ──▶ Workflow (طراحی سرفصل ▶ نوشتن اسلایدها ▶ ساخت و ارسال فایل)
                         │                          │
                         └── KV: تنظیمات کاربر       └── مدل زبانی (OpenAI-compatible یا Claude) + Pexels (اختیاری)
```

- **Workers**: دریافت وبهوک و پاسخ فوری (۲۰۰) به تلگرام.
- **Workflows**: کار طولانی (۱ تا ۲ دقیقه) با تلاش مجدد خودکار برای هر گام؛ خطای کلید/مدل نادرست بی‌خودی تکرار نمی‌شود.
- **KV**: تنظیمات هر کاربر (تم، لحن، فونت، تعداد اسلاید) و شمارنده‌ی روزانه.
- **PptxGenJS**: جایگزین `python-pptx` (پایتون روی Workers قابل استفاده برای این کار نیست)؛ هفت چیدمان و پنج تم نسخه‌ی قبلی حفظ شده است.

## استقرار با گیت‌هاب (بدون هیچ دستور محلی)

1. **ساخت ربات**: در تلگرام با `@BotFather` دستور `/newbot` را بزنید و توکن را نگه دارید.
2. **گیت‌هاب**: این پوشه را در یک مخزن (ترجیحاً Private) بگذارید. فایل `.env` قدیمی را **هرگز** در مخزن نگذارید (`.gitignore` جلوی آن را می‌گیرد).
3. **اتصال به کلودفلر**: داشبورد ← *Workers & Pages* ← *Create application* ← *Import a repository* (Connect GitHub) و مخزن را انتخاب کنید.
   - نام Worker: `persian-ppt-bot` (باید با `name` در `wrangler.jsonc` یکی باشد)
   - Build command: خالی — Deploy command: `npx wrangler deploy`
   - با هر push به شاخه‌ی اصلی، کلودفلر خودش دوباره می‌سازد و دیپلوی می‌کند.
   - در اولین دیپلوی، Wrangler خودش KV را می‌سازد و Workflow با نام `persian-ppt-deck` را ثبت می‌کند.
4. **رمزها**: Worker ← *Settings* ← *Variables and Secrets* ← مقادیر زیر را با نوع **Secret** اضافه کنید (همین بخش، نه «Build variables»):

   | نام | توضیح |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | توکن BotFather |
   | `TELEGRAM_WEBHOOK_SECRET` | یک رشته‌ی تصادفی بلند فقط با `A-Z a-z 0-9 _ -` |
   | `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` | هر API سازگار با OpenAI (پیش‌فرض: gapgpt و `gpt-4o-mini`) |
   | `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | جایگزین برای Claude (پیش‌فرض مدل: `claude-sonnet-5-5`) |
   | `LLM_PROVIDER` | اختیاری: `openai` یا `anthropic` برای انتخاب اجباری |
   | `PEXELS_API_KEY` | اختیاری: تصویر خودکار اسلایدهای «تصویر و متن» |
   | `ALLOWED_USER_IDS` | اختیاری: شناسه‌ی عددی کاربران مجاز با کاما (خالی = همه). شناسه‌ی خود را با `/id` در ربات ببینید |
   | `DAILY_LIMIT` | اختیاری: سقف روزانه‌ی هر کاربر (پیش‌فرض ۵، `0` = نامحدود) |

   بدون کلید مدل، ربات در «حالت نمایشی» با متن نمونه کار می‌کند؛ برای تست اتصال مناسب است.
5. **ثبت وبهوک** (فقط یک بار): این آدرس را در مرورگر باز کنید:
   `https://persian-ppt-bot.<ساب‌دامین-شما>.workers.dev/setup?secret=<TELEGRAM_WEBHOOK_SECRET>`
   اگر `{"ok":true,...}` دیدید، در تلگرام `/start` را بزنید.

## پلن و هزینه

پلن رایگان Workers فقط **۱۰ میلی‌ثانیه CPU** برای هر فراخوانی/گام Workflow می‌دهد. ساخت فایل PPTX در تست من برای یک ارائه‌ی کوچک نزدیک همین حد بود، پس روی پلن رایگان ممکن است گاهی با خطای CPU قطع شود. برای پایداری پلن **Workers Paid (۵ دلار در ماه)** را پیشنهاد می‌کنم. هزینه‌ی اصلی در هر حال API مدل زبانی است؛ `DAILY_LIMIT` و `ALLOWED_USER_IDS` را برای جلوگیری از سوءاستفاده تنظیم کنید.

## نکات

- فونت Vazirmatn داخل فایل امبد نمی‌شود؛ باید روی دستگاه نمایش‌دهنده نصب باشد (Tahoma و Arial همه‌جا کار می‌کنند).
- رنگ نشانه‌ی بولت‌ها با رنگ متن یکی است (PptxGenJS رنگ جدا برای بولت ندارد).
- تصویر اسلایدها را خود Pexels هم‌اندازه‌ی کادر برش می‌دهد؛ پردازش تصویر در Worker انجام نمی‌شود.
- شمارنده‌ی روزانه روی KV است (همگام‌سازی لحظه‌ای ندارد)؛ برای کنترل هزینه کافی است، نه سد دقیق.
- متن مدل ممکن است آمار یا اطلاعات نادرست بنویسد؛ پیش از ارائه بررسی کنید.
- اگر دیپلوی روی ساخت خودکار KV خطا داد: `npx wrangler kv namespace create KV` و شناسه را در `wrangler.jsonc` زیر `kv_namespaces` به‌صورت `"id"` بگذارید.

## توسعه و عیب‌یابی

```bash
npm install
cp .dev.vars.example .dev.vars   # مقادیر را پر کنید
npm run sample                   # ساخت sample.pptx بدون نیاز به کلید یا اینترنت
npm run typecheck
npm run dev                      # اجرای محلی (برای وبهوک واقعی به تونل مثل cloudflared نیاز است)
```

لاگ و وضعیت: `npx wrangler tail` و `npx wrangler workflows instances list persian-ppt-deck`، یا تب *Workflows* در داشبورد.
