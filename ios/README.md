# اپ iOS پاورپوینت‌ساز (SwiftUI بومی)

اپ بومی iPhone/iPad با **SwiftUI** (حداقل iOS 16) که مستقیم با همان API سایت (`https://pptsaz.ir/api/...`) و همان حساب اپ اندروید و وب کار می‌کند. ظاهر آن عمداً از قواعد iOS پیروی می‌کند، نه کپی اندروید: TabBar پایین، عنوان‌های بزرگ، فهرست‌های inset-grouped، sheet با detent، هپتیک، QuickLook، ShareLink و Safari داخل‌برنامه برای درگاه پرداخت. تمام رابط راست‌به‌چپ است و حالت تیره هم پشتیبانی می‌شود.

## امکانات
- ورود با کد پیامکی (یا ایمیلی اگر سرور فعال کرده باشد)؛ نشست ماندگار
- **ساخت:** موضوع، تعداد اسلاید (با قفل پلن)، تصویر، جزوه‌ی Word، پوستر افقی/عمودی، اسلاید صوتی، پادکست، منبع از متن/PDF/عکس (OCR سرور)/لینک؛ پیگیری زنده‌ی پیشرفت و ادامه‌ی پیگیری بعد از بستن اپ
- **فایل‌ها:** فهرست ۲۴ ساعت اخیر و نمونه‌ها، پیش‌نمایش اسلایدها، باز کردن PPTX/Word/PDF/پوستر/صدا با QuickLook (و ذخیره/ارسال با اشتراک‌گذاری)، ساخت جداگانه‌ی پوستر/جزوه/صدا
- **تنظیمات:** قالب، تم رنگی، فونت، لحن، حالت ساخت، ارقام فارسی، منابع، پرسش‌های پایانی، تصویر، مدل هوش مصنوعی
- **حساب:** اعتبار، پلن‌ها و خرید از درگاه (Safari داخل اپ)، پروفایل و هدیه‌ی تکمیل پروفایل، دعوت دوستان، چت پشتیبانی هوشمند، ربات تلگرام

قیمت پلن‌ها از سرور می‌آید (`/api/me` ← `plans`)؛ هیچ قیمتی در اپ ثابت نیست، پس با تغییر `src/payment.ts` خودکار به‌روز می‌شود.

## عمداً در این نسخه نیست
اعلان Push (نیاز به حساب Apple Developer و APNs دارد)، ورود با گوگل، ورودی صوتی، ویجت.

## ساخت IPA در GitHub
Actions ← «Build iOS app (native)» ← Run workflow (با تغییر پوشه‌ی `ios/` خودکار هم اجرا می‌شود).
مراحل: ساخت پروژه با XcodeGen ← تست واحد روی شبیه‌ساز ← ساخت Release ← بسته‌بندی IPA.
خروجی: artifact با نام `pptsaz-ios` شامل:
- `pptsaz-unsigned.ipa`: **بدون امضا**؛ برای نصب باید با AltStore، Sideloadly یا TrollStore امضا/نصب شود (به حساب توسعه‌دهنده نیاز ندارد؛ Apple ID رایگان کافی است ولی هر ۷ روز باید تمدید شود).
- `pptsaz-signed.ipa`: فقط اگر Secrets زیر تنظیم باشد (Ad Hoc، با حساب Apple Developer پولی):
  `IOS_CERT_P12_B64`، `IOS_CERT_PASSWORD`، `IOS_PROVISION_B64`، `IOS_TEAM_ID`

## ساخت محلی (روی مک)
```
brew install xcodegen
cd ios && xcodegen generate && open PptSaz.xcodeproj
```

## نکته‌ی انتشار
Bundle ID: `ir.pptsaz.app`. اگر روزی بخواهید در App Store منتشر کنید، اپل برای کالای دیجیتال خرید درون‌برنامه‌ای (StoreKit) می‌خواهد و پرداخت از درگاه بیرونی پذیرفته نمی‌شود؛ برای توزیع مستقیم IPA مشکلی نیست.
