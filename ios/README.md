# اپ iOS پاورپوینت‌ساز (SwiftUI بومی)

اپ بومی iPhone/iPad با **SwiftUI** (حداقل iOS 16) که مستقیم با همان API سایت (`https://pptsaz.ir/api/...`) و همان حساب اپ اندروید و وب کار می‌کند. ظاهر آن عمداً از قواعد iOS پیروی می‌کند، نه کپی اندروید: TabBar پایین، عنوان‌های بزرگ، فهرست‌های inset-grouped، sheet با detent، هپتیک، QuickLook، ShareLink و Safari داخل‌برنامه برای درگاه پرداخت. تمام رابط راست‌به‌چپ است و حالت تیره هم پشتیبانی می‌شود.

## امکانات
- ورود با کد پیامکی (یا ایمیلی اگر سرور فعال کرده باشد)؛ نشست ماندگار
- **ساخت:** موضوع، تعداد اسلاید (با قفل پلن)، تصویر، جزوه‌ی Word، پوستر افقی/عمودی، اسلاید صوتی، پادکست، منبع از متن/PDF/عکس (OCR سرور)/لینک؛ پیگیری زنده‌ی پیشرفت و ادامه‌ی پیگیری بعد از بستن اپ
- **فایل‌ها:** فهرست ۲۴ ساعت اخیر و نمونه‌ها، پیش‌نمایش اسلایدها، باز کردن PPTX/Word/PDF/پوستر/صدا با QuickLook (و ذخیره/ارسال با اشتراک‌گذاری)، ساخت جداگانه‌ی پوستر/جزوه/صدا
- **تنظیمات:** قالب، تم رنگی، فونت، لحن، حالت ساخت، ارقام فارسی، منابع، پرسش‌های پایانی، تصویر، مدل هوش مصنوعی
- **حساب:** اعتبار، پلن‌ها و خرید از درگاه (Safari داخل اپ)، پروفایل و هدیه‌ی تکمیل پروفایل، دعوت دوستان، چت پشتیبانی هوشمند، ربات تلگرام

قیمت پلن‌ها از سرور می‌آید (`/api/me` ← `plans`)؛ هیچ قیمتی در اپ ثابت نیست، پس با تغییر `src/payment.ts` خودکار به‌روز می‌شود.

## عمداً در این نسخه نیست
اعلان Push (نیاز به حساب Apple Developer و APNs دارد)، ورود با گوگل، ورودی صوتی، ویجت.

## ساخت IPA در GitHub
Actions ← «Build iOS app (native)» ← Run workflow (با تغییر پوشه‌ی `ios/` خودکار هم اجرا می‌شود).
مراحل: ساخت پروژه با XcodeGen ← تست واحد روی شبیه‌ساز ← ساخت Release ← بسته‌بندی IPA.
خروجی: artifact با نام `pptsaz-ios` شامل:
- `pptsaz-unsigned.ipa`: **بدون امضا**؛ برای نصب باید با AltStore، Sideloadly یا TrollStore امضا/نصب شود (به حساب توسعه‌دهنده نیاز ندارد؛ Apple ID رایگان کافی است ولی هر ۷ روز باید تمدید شود).
- `PptSaz.xcarchive.zip`: آرشیو Xcode؛ اگر استور خروجی IPA خودتان را نپذیرفت، روی یک مک با SibApp Export از همین آرشیو خروجی بگیرید.
- `screenshots/`: ۷ اسکرین‌شات برای صفحه‌ی معرفی اپ (ورود، ساخت، پیشرفت ساخت، فایل‌ها، جزئیات فایل، تنظیمات، پلن‌ها) از شبیه‌ساز iPhone Pro Max.
- `pptsaz-signed.ipa`: فقط اگر Secrets زیر تنظیم باشد (Ad Hoc، با حساب Apple Developer پولی):
  `IOS_CERT_P12_B64`، `IOS_CERT_PASSWORD`، `IOS_PROVISION_B64`، `IOS_TEAM_ID`

## اسکرین‌شات‌ها و حالت دمو
اسکرین‌شات‌ها با «حالت دمو» ساخته می‌شوند: اپ با آرگومان اجرای `-demo YES` به‌جای شبکه از داده‌ی نمونه‌ی `DemoData.swift` استفاده می‌کند (آرگومان‌های `-demoTab 0..3`، `-demoJob YES`، `-demoFile YES`، `-demoScroll YES`، `-demoLogin YES`). این حالت فقط با آرگومان اجرا روشن می‌شود و کاربر عادی هرگز آن را نمی‌بیند. برای عوض کردن متن یا قیمت نمونه، `DemoData.swift` را ویرایش کنید.

## ساخت محلی (روی مک)
```
brew install xcodegen
cd ios && xcodegen generate && open PptSaz.xcodeproj
```

## نکته‌ی انتشار
Bundle ID: `ir.pptsaz.app`. اگر روزی بخواهید در App Store منتشر کنید، اپل برای کالای دیجیتال خرید درون‌برنامه‌ای (StoreKit) می‌خواهد و پرداخت از درگاه بیرونی پذیرفته نمی‌شود؛ برای توزیع مستقیم IPA مشکلی نیست.

## نسخه‌ی سیب‌اپ (خرید درون‌برنامه‌ای)
Workflow علاوه بر `pptsaz-unsigned.ipa` فایل `pptsaz-sibapp-unsigned.ipa` را هم می‌سازد (با `PPTSAZ_STORE=sibapp`؛ همان کد و همان Bundle ID). در این نسخه دکمه‌ی خرید پلن به‌جای درگاه Safari، سیب‌اپ را با `sibapp://package_purchase?package=…&developer_payload=…` باز می‌کند و بعد از خرید، سیب‌اپ اسکیم `pptsaz://?purchase_id=…` را باز می‌کند؛ اپ شناسه را به `POST /api/pay/sibapp` می‌فرستد و سرور با Validate تایید، پلن را فعال و خرید را Consume می‌کند.

تنظیم:
1. پنل سیب‌اپ ← اپ ← خرید: برای هر پلن یک بسته‌ی **خریدنی** با قیمت دقیقاً برابر قیمت پلن بسازید (پلاس ۷۹۰٬۰۰۰ تومان، پرو ۱٬۳۴۰٬۰۰۰ تومان) و یک **توکن** بسازید.
2. همان‌جا در «تنظیمات بسته‌های درون‌اپی» اسکیم اپ را `pptsaz` بگذارید.
3. در Cloudflare: secret با نام `SIBAPP_TOKEN` = توکن؛ متغیر `SIBAPP_PACKAGES` = `plus:<شناسه‌ی بسته‌ی پلاس>,pro:<شناسه‌ی بسته‌ی پرو>`؛ اختیاری: `SIBAPP_APP_ID`.
4. اگر IP سرور برای توکن الزامی بود، به‌خاطر اجرای Worker روی Cloudflare آدرس ثابتی ندارید؛ در تنظیم توکن محدودیت IP نگذارید.

### آنچه عمداً نیست (نیاز به حساب Apple Developer یا افزونه‌ی جدا دارد)

- Push واقعی (APNs)، ورود با Apple، iCloud، Universal Links (Associated Domains)، Time‑Sensitive Notifications.
- ویجت و Live Activity و Share Extension: افزونه (Extension) جدا می‌خواهند و ساخت بدون امضای رسمی را شکننده می‌کنند.
- پنجره‌ی امتیازدهی (`requestReview`) فقط برای اپ‌های App Store کار می‌کند.

### محدودیت مهم اعلان‌ها

بدون Push، iOS اجازه نمی‌دهد اپِ کاملاً بسته‌شده هر لحظه کد اجرا کند. برای همین «آماده شد» هنگامی که اپ در پس‌زمینه است
(نه force‑quit) و iOS وظیفه‌ی پس‌زمینه را اجرا کند فوراً می‌آید؛ در غیر این صورت اعلان پشتیبان «احتمالاً آماده است» بعد از ۴ دقیقه می‌رسد.
یادآورهای هوشمند هر بار که اپ باز می‌شود یا رویدادی رخ می‌دهد از نو زمان‌بندی می‌شوند (iOS هنگام نمایش اعلان شرطی را بررسی نمی‌کند).

### آزمون دستی پیشنهادی

1. ساخت ارائه ← رفتن به صفحه‌ی اصلی ← تا ~۳۰ ثانیه ← اعلان «آماده شد» ← زدن روی «دانلود».
2. حالت پرواز: «فایل‌ها ← ذخیره‌شده روی گوشی» باید باز شود.
3. نگه‌داشتن آیکن ← «ارائه‌ی جدید».
4. Files ← On My iPhone ← پاورپوینت‌ساز: فایل‌های ذخیره‌شده دیده شوند.
5. تنظیمات ← قفل اپ را روشن کن و اپ را به پس‌زمینه ببر.
