# اپ اندروید پاورپوینت‌ساز (بومی)

اپ کاملاً بومی (Kotlin + Jetpack Compose) که مستقیم با API سایت (`https://pptsaz.ir/api/...`) حرف می‌زند؛ ورود، ساخت، فایل‌ها و خرید کاملاً بومی‌اند و به Chrome وابسته نیست (فقط صفحه‌ی پیش‌نمایش اسلایدها در یک WebView کوچک باز می‌شود).

## امکانات
- ورود فقط با شماره‌ی موبایل و کد پیامکی (نشست ماندگار)
- ساخت ارائه: موضوع، تعداد اسلاید، متن منبع (تایپی، از PDF/عکس یا از لینک صفحه‌ی وب)، جزوه‌ی Word، پیگیری پیشرفت (حتی بعد از بستن و باز کردن اپ)
- پوستر (افقی/عمودی): ساخت، نمایش داخل اپ و دانلود
- پیش‌نمایش اسلایدها (سرور آن را به‌صورت صفحه‌ی HTML می‌سازد؛ فقط همین صفحه داخل یک WebView کوچک نشان داده می‌شود)
- فهرست فایل‌ها و دانلود (PPTX / Word) در پوشه‌ی Downloads و باز کردن فایل
- حساب: ویرایش نام، اعتبار، اشتراک‌ها و خرید (پرداخت در مرورگر)، تنظیمات قالب/رنگ/لحن/فونت و انتخاب مدل هوش مصنوعی، خروج

## هنوز در اپ نیست (فقط در سایت)
ورود با گوگل و تلگرام، و اتصال تلگرام به حساب.

## مشخصات
- پکیج `ir.pptsaz.app` (همان قبلی؛ با همان keystore امضا می‌شود)، `minSdk 24`، `targetSdk 34`

## بیلد
Actions → «Build Android app (native)» → Run workflow (اسم workflow همان مانده؛ می‌توانید عوض کنید).
Secrets: `ANDROID_KEYSTORE_B64` و `ANDROID_KEYSTORE_PASSWORD` (alias کلید: `pptsaz`).
خروجی: artifact با نام `pptsaz-android` (فایل‌های `pptsaz.apk` و `pptsaz.aab`).
