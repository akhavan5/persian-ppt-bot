# اپ اندروید پاورپوینت‌ساز (بومی)

اپ کاملاً بومی (Kotlin + Jetpack Compose) که مستقیم با API سایت (`https://pptsaz.ir/api/...`) حرف می‌زند؛ نه WebView دارد و نه به Chrome وابسته است.

## امکانات نسخه‌ی ۲.۰
- ورود با شماره‌ی موبایل و کد پیامکی (نشست ماندگار)
- ساخت ارائه: موضوع، تعداد اسلاید، متن منبع، جزوه‌ی Word، پیگیری پیشرفت (حتی بعد از بستن و باز کردن اپ)
- فهرست فایل‌ها و دانلود (PPTX / Word) در پوشه‌ی Downloads و باز کردن فایل
- حساب: اعتبار، اشتراک‌ها و خرید (پرداخت در مرورگر)، تنظیمات قالب/رنگ/لحن/فونت، خروج

## هنوز در اپ نیست (فقط در سایت)
آپلود PDF/عکس، لینک به‌عنوان منبع، پوستر، پیش‌نمایش اسلایدها، ورود با گوگل/تلگرام، ویرایش پروفایل.

## مشخصات
- پکیج `ir.pptsaz.app` (همان قبلی؛ با همان keystore امضا می‌شود)، `minSdk 24`، `targetSdk 34`

## بیلد
Actions → «Build Android app (native)» → Run workflow (اسم workflow همان مانده؛ می‌توانید عوض کنید).
Secrets: `ANDROID_KEYSTORE_B64` و `ANDROID_KEYSTORE_PASSWORD` (alias کلید: `pptsaz`).
خروجی: artifact با نام `pptsaz-android` (فایل‌های `pptsaz.apk` و `pptsaz.aab`).
